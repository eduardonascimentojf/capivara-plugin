Guia de Instalação e Uso Geral

Aprenda a instalar o plugin Capivara na sua própria instância do Eclipse e configurá-lo para realizar análises de fluxo de controle e cobertura estrutural de código Java.

1. Instalação do Plugin

Escolha um dos dois métodos abaixo para adicionar o Capivara ao seu Eclipse (Recomendado: Java 17+ e Eclipse 2025-03 ou superior).

Método 1: Pelo Update Site (Recomendado)

Este método permite que o Eclipse gerencie o plugin e busque atualizações automaticamente.

  1. No menu superior do seu Eclipse, acesse Help > Install New Software...
  2. Clique no botão Add... no canto superior direito.
  3. No campo Name coloque Capivara Update Site e no campo Location insira a URL estável: 
    https://eduardonascimentojf.github.io/capivara-plugin/
  4. Clique em Add. Marque a caixinha correspondente ao "Capivara Tools" que aparecerá na lista.
  5. Avance clicando em Next, aceite os termos e clique em Finish.
  6. Se a IDE exibir um alerta sobre "Trust Artifacts" (Artefatos não assinados), clique em Select All e confirme em Trust Selected.
  7. Reinicie o Eclipse para concluir a ativação.

Método 2: Instalação Manual via Dropins

Caso sua rede bloqueie downloads internos do Eclipse, você pode realizar a instalação offline:

  1. Acesse a aba Releases no repositório do projeto no GitHub e baixe o arquivo compilado .jar da versão desejada.
  2. Feche o seu Eclipse.
  3. Navegue até o diretório onde o Eclipse está instalado no seu computador.
  4. Localize a pasta chamada dropins (caso ela não exista na raiz da instalação, você pode criá-la com esse nome exato).
  5. Cole o arquivo .jar baixado dentro dessa pasta.
  6. Abra o Eclipse novamente. O plugin será detectado e carregado na inicialização.

2. Configuração do Graphviz

O Capivara possui um motor gráfico interno (ELK), mas a visualização, distribuição e espaçamento dos grafos ficam consideravelmente superiores quando o Graphviz está instalado no sistema operacional. O plugin tentará localizar de forma automática o executável do Graphviz nos caminhos padrões:

  • No Windows: O plugin busca o executável automaticamente nas pastas: 
    C:\Program Files\Graphviz\bin\dot.exe
    ou 
    C:\Program Files (x86)\Graphviz\bin\dot.exe
    Certifique-se de marcar a opção "Add Graphviz to the system PATH" durante o instalador oficial do Windows.
  • No Linux: O utilitário deve estar acessível globalmente pelo terminal através do comando dot. Você pode instalá-lo rapidamente usando o gerenciador de pacotes da sua distribuição (ex: sudo apt install graphviz). O link simbólico será criado automaticamente em /usr/bin/dot.
⚠️ Comportamento de Layout:
• Se o Graphviz não for encontrado, o plugin usará o motor padrão do ELK.
• No Windows, normalmente existe um delay para o plugin pegar o path do .dot. Caso demore para aplicar o layout, verifique se o path está correto e reinicie o Eclipse.
• Caso os nós apareçam sobrepostos ou desalinhados, basta acionar a geração do grafo novamente para reajustar a distribuição.

3. Como Utilizar no seu Código

O analisador do Capivara trabalha com foco em escopo intra-método, avaliando um método por vez. Chamadas para outras classes são representadas no grafo como nós únicos de processamento sequencial.

Dica de Seleção:
• Na geração do GFC: Caso você opte por selecionar o bloco de código manualmente em vez de usar o atalho da assinatura, é necessário que o início da seleção seja exatamente o início do método e o final seja o fechamento de sua última chave. O parser exige que não haja nada antes ou depois da estrutura selecionada (como quebras de linha órfãs, indentações externas ou comentários fora do escopo). Esta mesma regra de bloco estrito se aplica à Análise de Cobertura.
• Na Enumeração de Nós: O mecanismo é consideravelmente mais flexível. Basta que o método alvo esteja contido em algum ponto dentro da área selecionada para que o plugin consiga realizar o mapeamento das linhas perfeitamente.

A. Enumeração de Nós (Node Enumeration)

Associa as linhas de comando do seu método aos nós abstratos equivalentes do fluxo de controle.

  1. Abra qualquer classe Java no seu projeto e selecione o método alvo.
  2. Clique com o botão direito e selecione Capivara | Node Enumeration.
  3. Os nós mapeados serão exibidos em uma aba dedicada integrada à IDE. Caso ela suma, recupere-a em: Window > Show View > Other... > Capivara Analysis.

B. Gerar Grafo de Fluxo de Controle (GFC)

Cria o diagrama visual e interativo do fluxo logístico da rotina.

  1. Clique com o botão direito sobre o método selecionado e escolha Capivara | Generate GFC.
  2. O arquivo do modelo gráfico será aberto imediatamente na tela. Você pode arrastar os nós e arestas livremente para organizar a exibição.
  3. Passe o ponteiro do mouse sobre os nós ou arestas para ler as informações detalhadas em caixas de texto flutuantes (Tooltips).

C. Análise e Plotagem de Cobertura de Testes

Coloriza o grafo do fluxo de controle integrando dados reais obtidos pela execução de testes de software.

  1. Passo Obrigatório: Antes de mais nada, execute a sua classe ou suíte de testes (JUnit) utilizando o botão de cobertura do EclEmma (o ícone do triângulo "Play" acompanhado de listras verdes na barra de ferramentas superior do Eclipse).
  2. Com o método Java selecionado no editor, clique com o botão direito e vá em Capivara | Coverage Analysis GFC.
  3. Escolha o critério estrutural desejado para colorização:
    • Node Coverage: Realça em cores o percentual de nós e instruções visitadas de forma direta.
    • Edge Coverage: Realça as ramificações de caminhos tomados (ramos/decisões Verdadeiro e Falso).
  4. O grafo aberto incorporará as cores (Verde para coberto, Vermelho para não executado, Amarelo para parcial), permitindo identificar facilmente lacunas de testes.
  5. Para extrair o relatório visual, clique com o botão direito em uma área livre do diagrama e selecione Export Diagram as PNG.
